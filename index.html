常见问题解答Frequently Asked Questions

BiWrite 收费吗？需要注册账号吗？ Is BiWrite free? Do I need an account?

软件完全免费并基于 MIT 协议开源，无任何账号体系或订阅收费。你只需配置自己的模型接口密钥（官方 API、第三方兼容接口或本地免费的 Ollama / LM Studio 均可）。

BiWrite is 100% free and MIT open-source with no account or subscription. You simply connect your own API key (official providers, compatible relays, or local free servers like Ollama).

我的论文源码和 API 密钥安全吗？会经过第三方服务器吗？ Where are my manuscripts and API keys stored?

所有源码、SQLite 翻译缓存与请求日志仅保存在你的电脑本地，软件不包含任何统计或遥测代码。API 请求由你本机直接发往你填写的模型接口地址；密钥保存在本机仅当前系统账户可读的配置文件或系统钥匙串中，日志绝不记录密钥明文。

Manuscripts, SQLite translation caches, and request logs never leave your machine, with zero telemetry. API calls go directly from your desktop to your configured endpoint, and keys stay in local user-only storage or your OS keychain.

我已经有一份手写的中文版论文，怎么和英文版同步维护？ Can I pair an existing manually written Chinese version?

把中文稿命名为 paper_zh.tex 放在 paper.tex 旁（或使用 sections_en/ 与 sections_zh/ 目录），打开时即自动逐段对齐，也可点标题栏链条图标手动选择配对文件。配对后直接显示你的中文，零翻译请求；改任意一侧，保存时另一侧只原位替换对应段落。

Place paper_zh.tex beside paper.tex (or use sections_en/ and sections_zh/) for automatic alignment, or click the Pair icon in the toolbar. Your Chinese text loads with zero API requests, and edits sync in place when you save.

不保存直接编译，或者使用写作助手，会改坏我磁盘上的原文件吗？ Will unsaved builds or assistant actions overwrite my files on disk?

不会。未保存编译在隐藏的 .biwrite/ 缓存目录中进行，助手的「采纳」与「还原」也只修改编辑器内存中的内容（且随时可 ⌘Z 撤销）。只有你按下 ⌘S 保存时才写入本地文件；若期间文件被外部程序（如 Git）修改过，保存前还会弹出逐行 Diff 提醒。

Never. Unsaved builds run inside a hidden .biwrite/ cache folder, and assistant edits apply only to the in-memory editor buffer (undoable via ⌘Z). Disk files are written only on Save, with a line-by-line diff prompt if modified externally.

第三方接口容易遇到 429 限流或疑似降智，怎么处理？ How does BiWrite handle API rate limits or unreliable relays?

在接口设置中打开「管理号池」粘贴多个密钥并设定单 Key 并发，软件会自动均衡调度并在限流时秒切可用 Key，也可在「请求节奏」中调大单次合并段落数（1–8 段）。按 ⌘⇧L 打开请求日志，可直接核对服务端实际返回的模型名称、推理强度与服务等级是否与请求一致。

Add multiple keys in the Key Pool with per-key concurrency limits for automatic load balancing and cooldown failover, or batch 2–8 new paragraphs per request. Open the Request Log (⌘⇧L) to inspect server-declared model names, reasoning effort, and service tiers.

可以直接写中文初稿，让右侧实时生成英文论文吗？ Can I write my primary draft in Chinese and translate into English?

完全支持。打开中文文档时软件会自动识别为「左中右英」（zh → en）模式；英文文档也可以随时点顶部的 EN ⇄ 中 切为中文侧编辑，编译英文 PDF 或导出英文 .tex 同样一键完成。

Yes. Opening a Chinese manuscript automatically sets Chinese as the primary editor with English generated on the right (zh → en), and you can export or compile the English LaTeX PDF directly.
